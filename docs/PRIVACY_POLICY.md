# Privacy Policy — TurfRoute

The canonical, public privacy policy is **[`public/privacy.html`](../public/privacy.html)**. It is deployed with the
web app at `https://collins-lawncare-tracker.vercel.app/privacy.html` (see `BRAND.privacyPolicyUrl` in
`src/brand.js`) and linked from the sign-in screen, Settings and the TurfRoute Pro paywall.

Enter that URL in App Store Connect → App Information → **Privacy Policy URL**. Keep it in sync with the
App Privacy answers in [`IOS_APP_STORE.md`](../IOS_APP_STORE.md).

> The previous version of this file said the app had no accounts or backend. That is no longer true
> (Firebase Auth + Firestore sync, Stripe customer payments, SendGrid emails), so it was replaced.
